Class Management System – Phase 1 Requirements
1. User Roles
The system will support the following roles with different access levels:
1. Super Admin
(Owner / Head)
Permissions:
View complete analytics
Manage admins
Manage teachers
Manage students
View financial overview
View teacher performance
View student performance
View syllabus completion
View feedback
View attendance
View tests & performance
2. Admin
(Main operational role)
Permissions:
Add / Edit Students
Add / Edit Teachers
Manage Admissions
Manage Attendance
Manage Fees
Manage Stationery
Manage Timetable
Upload syllabus
Track syllabus completion
Upload test results
Manage lead enquiries
Generate reports
Admin is responsible for most daily entries.
3. Teacher


===== PAGE 2 =====
Teacher can:
Login to teacher dashboard
Mark class start (IN)
Mark class end (OUT)
Enter topics taught
Select chapter / subtopics covered
Assign homework
Assign assignments
Upload weekly syllabus plan
Enter test marks
Add remarks about student
Teacher cannot see student feedback about them.
4. Student
Students can:
Login to student portal
View attendance
View test results
View syllabus progress
View homework
View assignments
Give lecture feedback
View teacher announcements
5. Parent
Parents can view:
Student attendance
Test marks
Performance report
Fee status
Syllabus progress
Teacher remarks
Notifications
Parents see only their child’s data.
